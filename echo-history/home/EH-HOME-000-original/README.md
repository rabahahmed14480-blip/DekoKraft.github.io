# EH-HOME-000 — Original Home

Status: Current, Restart Point

## Purpose

Preserve the current DekoKraft / Echo homepage before beginning
the new layered Echo homepage architecture.

## Existing State

This version represents the homepage before:

- Bridge background layer
- New Echo layered homepage
- Companion Lamp entry
- Voice-first Companion integration

- New Entry Card integration

## Why Preserve This Version?

EH-HOME-000 is the baseline of the new Echo development history.

It allows future development to:

- Return to the original homepage.
- Compare old and new designs.
- Start a completely new design from this point.
- Understand how the Echo homepage evolved.
